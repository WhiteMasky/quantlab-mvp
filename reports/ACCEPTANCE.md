### 实际浏览器工作流

使用本机 Google Chrome 138.0.7204.157 + Playwright Core，没有用静态截图替代交互。首次完整流程：

1. 空账本真实 $100,000 现金，无伪造收益。
2. lookback=9 被前端拒绝，不能提交。
3. 默认趋势实际计算，显示 504 个观测点、真实基准/回撤及独立模拟账本的 4 笔成交。
4. 1440px 桌面六页可用，无文档横向溢出。
5. 订单搜索无匹配状态、成交切换、实际导出文件均可用。
6. 相同实验重跑读取封存结果，既有成交不重复。
7. 动量研究仍在计算时点击 Halt，368ms 收到确认，随后健康检查仍显示研究繁忙。
8. 动量结果返回但执行 0 单、0 成交，四个意图因 halted 被拒绝；撤单需要另一独立勾选确认，未改变组合或清仓。
9. 390px 移动导航、总览和订单表格无文档横向溢出。
10. 浏览器注入一次 `/api/state` 503，保留旧证据并标记待核实，显式刷新恢复。

首次最后一步检查控制台时发现 `/favicon.ico` 404，因此原始 `browser-acceptance.json` **故意保留 `failed`**，没有改写历史。加入内嵌 SVG 图标后，针对既有账本重新浏览六页、净值/回撤、基准显隐、观测滑块、移动菜单、503 恢复和无新增成交，共六项定向回归通过，零未预期控制台错误、零页面异常。故意注入的 503 被明确记录，不当作静默忽略的错误。

最终合并判断依赖“首次完整功能通过 + 静态图标修复 + 定向回归”，**没有声称修复后重新跑了一遍全新账本研究流程**。已有测试集封存和账本未删除。旧移动截图可能截到菜单收起动画，最终截图等待其隐藏后采集；没有为美化图片篡改收益或删风险标识。

## 故障行为与未混淆的证据

- 非法输入、NaN/布尔值冒充数字、无时区时间、重复/冲突数据、格式损坏：拒绝，不自动修补成可用行情。
- 重复意图相同载荷返回原记录；同 ID 不同载荷拒绝。超时或断线后的未知订单不盲目重发；需要恢复证据和对账。
- 乱序/重复回调不能重复入账；模拟部分成交、取消中状态和迟到成交有单独测试。
- 重启恢复订单/风控状态；实际持仓数量对不上“持久化起始仓位 + 唯一成交”时保持不 reconciled，不因空调用或重启解除屏障。
- stale quote/account、资金不足、越限、非交易时段、环境不可信均走拒绝式风控。风险单元测试不是实际券商行情认证。
- HTTP 失败不等于后端任务未执行；UI 保留旧结果、阻止不确定重试，服务端接受的作业不因浏览器断开而假装取消。
- Halt 确认与新单提交共用短临界区；研究长任务不持有此锁。Halt 默认只禁止新单，不等于取消已存在订单，更不等于卖出持仓。
- 某些引擎单元测试使用小型计算替身加快故障验证；真实计算证据来自 Python E2E、浏览器两策略结果和实际 CSV CLI，未将替身声称为实算。

## 复现和安全边界

在项目根目录：

```bash
bash scripts/dev.sh api
# 第二个终端
bash scripts/dev.sh web

# 验证软件，不触碰券商
/usr/local/bin/wybuild -- .venv/bin/python -m pytest --tb=short
PATH="$PWD/.tools/node/bin:$PATH" /usr/local/bin/wybuild -- npm --prefix frontend test
PATH="$PWD/.tools/node/bin:$PATH" /usr/local/bin/wybuild -- npm --prefix frontend run build
```

没有安装 wybuild 的其他主机可直接运行对应 Python/npm 命令。本机前端脚本已固定两个测试 worker，不要再次传同一 `--maxWorkers` 参数。CLI 研究命令和严格 CSV 字段见 README。

完整浏览器脚本 `scripts/browser-demo.mjs` 会修改离线测试账本并生成报告，要求初始账本为空；已有交付环境不是空账本。不要为重跑而删除证据、改封存记录或覆盖原报告。`create_app(runtime_dir=...)` 支持独立运行目录；建立新的软件测试夹具不构成重新开启真实研究测试集的授权。

整个开发没有：提交真实订单、连接用户 IBKR 账户、购买数据/服务、修改账户权限或安全设置、公开部署、删除用户数据、提交或推送代码。原 8000/5173 端口属于其他项目，因此采用新的本机端口，没有终止他人进程。诊断、审计和前端不包含真实账号凭据。
